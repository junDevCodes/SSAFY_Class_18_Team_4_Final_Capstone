# 추천 시스템 설계 v2.0: ALS 32차원 + 하이브리드 가중치

> **문서 버전**: v2.0.0
> **최종 수정일**: 2025년 12월 19일

---

## Executive Summary

본 문서는 기존 SVD 128차원 모델에서 **ALS 32차원 + 하이브리드 가중치** 시스템으로의 전환을 위한 종합 설계안입니다. 모든 설계 결정은 학술 논문과 실증 데이터에 기반합니다.

### 핵심 변경 사항

| 항목 | Before | After | 근거 |
|------|--------|-------|------|
| **알고리즘** | TruncatedSVD | ALS (Alternating Least Squares) | Implicit 최적화 |
| **차원** | 128 | 32 | Kaggle Rule of Thumb |
| **View 가중치** | ×1.0 | ×0.1 | 97% 노이즈 [1][5] |
| **Cart 가중치** | ×3.0 | ×2.0 | 25% 전환율 [5] |
| **하이브리드** | N/A | CBF 0.7 + CF 0.3 | Netflix Prize [1] |

├─────────────────────────────────────────────────────────────────────────────┤

│  Rule 1: 상호작용 기반 (Primary)                                            │
│  ─────────────────────────────────────────────────────────────────────────  │

│             ≤ 199                                                           │
│                                                                             │
│  Rule 3: 희소성 보정 (Sparsity Correction)                                   │

│  │  근거:                                                               │   │
│  │  1. Kaggle Rule 1, 2 모두 충족 (32 < 52 < 199)                      │   │
│  │  2. 2^5 = 32 → SIMD 벡터 연산 최적화                                 │   │
│  │  3. 희소 데이터에서 과적합 방지                                       │   │

## 2. 알고리즘 선택: SVD → ALS

### 2.1 왜 ALS인가?

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         SVD vs ALS 비교 분석                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                    TruncatedSVD (기존)                               │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │  장점:                                                               │   │
│  │  • 수학적으로 명확한 해석 (분산 설명률)                               │   │
│  │  • 구현 간단 (sklearn 내장)                                          │   │
│  │                                                                      │   │
│  │  단점:                                                               │   │
│  │  • Explicit Feedback 설계 (rating 기반)                              │   │
│  │  • 결측값 = 0으로 처리 → Implicit에 부적합                           │   │
│  │  • Confidence Weighting 미지원                                      │   │
│  │  • Cold Start 대응 어려움                                           │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                    ALS (신규)                                        │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │  장점:                                                               │   │
│  │  • Implicit Feedback 전용 설계 [Hu et al., 2008]                    │   │
│  │  • Confidence Weighting 네이티브 지원                               │   │
│  │  • 희소 행렬 최적화 (CSR format)                                    │   │
│  │  • 대규모 분산 처리 가능 (Spark MLlib)                              │   │
│  │  • 2017 IEEE ICDM 10년 최고 영향력 논문상 수상                       │   │
│  │                                                                      │   │
│  │  단점:                                                               │   │
│  │  • 설명 분산 개념 없음 (다른 평가 지표 필요)                          │   │
│  │  • 하이퍼파라미터 튜닝 필요 (α, λ, iterations)                      │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                    결론: ALS 선택                                    │   │
│  │                                                                      │   │
│  │  1. Implicit Feedback 데이터 → ALS가 정답                           │   │
│  │  2. Confidence Weighting으로 노이즈 처리                            │   │
│  │  3. Netflix Prize 우승 기법 (검증됨)                                │   │
│  │  4. 희소 행렬 최적화로 성능 향상                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 ALS 수학적 배경

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         ALS 수학적 기초                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  목적 함수 (Loss Function):                                                  │
│  ─────────────────────────────────────────────────────────────────────────  │
│                                                                             │
│  L = Σ C_ui × (p_ui - x_u^T × y_i)² + λ × (‖X‖² + ‖Y‖²)                    │
│                                                                             │
│  여기서:                                                                     │
│  • C_ui: 사용자 u의 아이템 i에 대한 신뢰도 (Confidence)                      │
│  • p_ui: 선호도 (1 if r_ui > 0, else 0)                                    │
│  • x_u: 사용자 u의 잠재 벡터 (32차원)                                       │
│  • y_i: 아이템 i의 잠재 벡터 (32차원)                                       │
│  • λ: 정규화 파라미터 (0.1)                                                 │
│                                                                             │
│  Confidence 계산:                                                           │
│  ─────────────────────────────────────────────────────────────────────────  │
│                                                                             │
│  C_ui = 1 + α × log(1 + r_ui)                                              │
│                                                                             │
│  • α = 15.0 (희소 데이터 권장 범위 10-20)                                   │
│  • r_ui = 상호작용 점수 (view×0.1 + cart×2.0 + order×5.0)                  │
│                                                                             │
│  최적화 (Alternating Least Squares):                                        │
│  ─────────────────────────────────────────────────────────────────────────  │
│                                                                             │
│  Step 1: Y 고정, X 업데이트                                                 │
│          x_u = (Y^T × C^u × Y + λI)^(-1) × Y^T × C^u × p(u)                │
│                                                                             │
│  Step 2: X 고정, Y 업데이트                                                 │
│          y_i = (X^T × C^i × X + λI)^(-1) × X^T × C^i × p(i)                │
│                                                                             │
│  반복: 15회 (수렴에 충분)                                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.3 Confidence Weighting 계산

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    Confidence Weighting 계산 예시                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  공식: C_ui = 1 + α × log(1 + r_ui)                                        │

│  ─────────────────────────────────────────────────────────────────────────  │
│                                                                             │
│  시나리오 1: 조회만 1회                                                      │
│  • r_ui = 0.1 × 1 = 0.1                                                    │

│                                                                             │

│  • r_ui = 5.0 × 1 = 5.0                                                    │

│  → 최고 신뢰도                                                              │

## 4. 하이브리드 모델 설계 (CBF 0.7 + CF 0.3)

### 4.1 하이브리드 필요성

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    하이브리드 모델 필요성                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  문제: 희소 데이터에서 CF 단독 사용의 한계                                     │

### 5.2 Python 구현

```python
# notebooks/utils/weight_config.py 참조

from dataclasses import dataclass
import numpy as np

@dataclass
class InteractionWeights:
    """상호작용 유형별 가중치 (전환율 역산 기반)"""
    view: float = 0.1       # 97% 노이즈
    wishlist: float = 0.5   # 명시적 관심
    cart: float = 2.0       # 25% 전환율
    review: float = 4.0     # 구매 후 만족도
    order: float = 5.0      # 기준점

@dataclass
class ConfidenceWeights:
    """Confidence Weighting 파라미터"""
    alpha: float = 15.0  # 희소 데이터 권장

    def calculate(self, score: float) -> float:
        return 1.0 + self.alpha * np.log1p(score)

@dataclass
class HybridWeights:
    """하이브리드 모델 가중치"""

    def get_dynamic_weights(self, interactions: int) -> tuple:
        cf_weight = min(0.7, interactions / 50)
        cbf_weight = 1.0 - cf_weight
        return cbf_weight, cf_weight

@dataclass
class TimeDecayWeights:
    """시간 감쇠 가중치"""
    decay_rate: float = 0.05  # λ, 반감기 ~14일

    def calculate(self, days: int) -> float:
        return np.exp(-self.decay_rate * days)

def compute_final_score(
    cbf_score: float,
    cf_score: float,
    interaction_count: int,
    days_since_last: int = 0
) -> float:
    """
    최종 추천 점수 계산

    Args:
        cbf_score: 콘텐츠 기반 점수 (0~1)
        cf_score: 협업 필터링 점수 (0~1)
        interaction_count: 사용자 총 상호작용 수
        days_since_last: 마지막 상호작용 이후 일수

    Returns:
        최종 점수 (0~1)
    """
    hw = HybridWeights()
    tdw = TimeDecayWeights()

    # 동적 가중치
    w_cbf, w_cf = hw.get_dynamic_weights(interaction_count)

    # 하이브리드 점수
    hybrid_score = w_cbf * cbf_score + w_cf * cf_score

    # 시간 감쇠
    if days_since_last > 0:
        time_weight = tdw.calculate(days_since_last)
        hybrid_score *= time_weight

    return hybrid_score
```
